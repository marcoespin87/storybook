# Layouts

The layout system is built on a responsive CSS grid. Use `.pbo-container` as the outer wrapper and `.pbo-row` to create grid rows. Column spans use Tailwind's `col-span-*` and `col-start-*` utilities with responsive prefixes.

## Breakpoints

Defined as `--pbo-breakpoint-*` and mapped to Tailwind variant prefixes.

export const breakpoints = [
  { prefix: 'xs', variable: '--pbo-breakpoint-xs', rem: '23.5rem', px: '376px' },
  { prefix: 'sm', variable: '--pbo-breakpoint-sm', rem: '36rem', px: '576px' },
  { prefix: 'md', variable: '--pbo-breakpoint-md', rem: '48rem', px: '768px' },
  { prefix: 'lg', variable: '--pbo-breakpoint-lg', rem: '62rem', px: '992px' },
  { prefix: 'xl', variable: '--pbo-breakpoint-xl', rem: '75rem', px: '1200px' },
  { prefix: '2xl', variable: '--pbo-breakpoint-2xl', rem: '96rem', px: '1536px' }
];

## Grid Columns

Each `col-span-*` value shown tiling across a full `.pbo-row`. From desktop (≥ 992px, `lg:`) the grid has **12 columns**, so spans 1–12 apply. On tablet (768px–991px, `md:`) the grid has **8 columns**, and on mobile **4 columns** — spans that exceed the column count fill the remaining space.

export const colSpanRows = [
  {
    label: 'col-span-1',
    spans: [
      'col-span-1',
      'col-span-1',
      'col-span-1',
      'col-span-1',
      'col-span-1',
      'col-span-1',
      'col-span-1',
      'col-span-1',
      'col-span-1',

      'col-span-1',
      'col-span-1'
    ]
  },
  {
    label: 'col-span-2',
    spans: ['col-span-2', 'col-span-2', 'col-span-2', 'col-span-2', 'col-span-2', 'col-span-2']
  },
  {
    label: 'col-span-3',
    spans: ['col-span-3', 'col-span-3', 'col-span-3', 'col-span-3']
  },
  {
    label: 'col-span-4',
    spans: ['col-span-4', 'col-span-4', 'col-span-4']

  {

    spans: ['col-span-6', 'col-span-6']
  },

    label: 'col-span-12',

<div class="flex flex-col gap-4">

</div>
