# Design System

This design system is built on top of **Tailwind CSS v4**.
All styles come from custom CSS variables (`--pbo-*`) mapped through `@theme`,
which means Tailwind auto-generates the utility classes for you.

## How it works

```css
/* Your CSS variables */
:root {
  --pbo-color-primary: #00693c;
}

/* Mapped in @theme */
@theme {
  --color-primary: var(--pbo-color-primary);
}

/* Tailwind generates -> bg-primary . text-primary . border-primary */

```

<div style={{ display: 'flex', flexDirection: 'column', gap: '0.5rem' }}>
